## Behavior
A separate owner-scoped table records recognized, replayable social URLs and completed server-side extraction outcomes. Partial results are distinct from total failures; native-caption success marks an existing case resolved, without recording ordinary successes. Attempts are retained until explicit deletion; no automatic retry or deletion. Browser-only failures, malformed/unrecognized URLs, denied/rate-limited requests and unavailable storage are not captured. Tracking query strings and fragments are intentionally not stored; required public content identifiers are preserved. Links are not proof of provider access. Existing diagnostics remain content-free. The owner can view, page, retry using the existing extraction path, delete a case, and explicitly export an individual attempt. The two assistant tools are read-only; reconnect/refresh discovery after deployment. No model calls.
