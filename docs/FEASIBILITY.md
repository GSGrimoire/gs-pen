# GS Pen feasibility protocol
Updated 22 October 2026.

## F0 Hosting
Confirm that private ChatGPT Site authentication applies before source operations, Site storage is owner-only, and browser inference runs in intended Chrome device. Measure quota and costs. GitHub Pages is insufficient by itself for authenticated storage or Python extraction.

## F1 Platforms
For Facebook/Reels, Instagram Reels, TikTok and YouTube/Shorts, use 10 rights-cleared public videos per platform, tested on at least two dates. Track URL, media rights, method, retrieved speech audio, original captions, post text, metadata, outcome, rate limits and permitted use. No credentials, cookies, anti-bot bypass or proxy evasion. A nonfunctioning extractor is a failure, not a passing result. Target at least 8/10 successful end-to-end retrievals on each test date for any advertised platform. The threshold is a proposed engineering gate and may require a scope decision.

## F2 Danish/English performance
Use short (1 minute), intermediate (5 minute) and 30-minute reference clips with explicit rights. Record browser, device, runtime, model revision, memory, download size, wall time and word error rate against manually corrected references. No silent audio omissions; cancellation must release memory and temporary data.

## F3 Owner security and storage
Verify denial of entry to unsigned visitors, second-account record isolation if possible, 50-entry cap, deletion across cache and synchronized database, and safe failure if sync is unavailable. Public GitHub code cannot contain personal content or secrets.

## F4 Compliance and privacy
Document processing purpose, data retention and user action on failure; confirm permitted methods for media and captions. Publicly viewable does not mean downloadable or authorized for machine learning/voice cloning.

## F5 Decision
Record one of Proceed, Revised scope, Stop with evidence. No general four-platform support claim before gate approval.

## Current evidence
